# Structure of a Latvian promocijas darba kopsavilkums

Latvian summaries follow a conventional shape and reviewers look for specific sections by name. When the English source is organized differently, map onto this structure and report the mapping. Do not delete source content that has no Latvian slot . place it in the nearest section and flag it.

Requirements vary by institution and by council. Where the receiving body publishes a template, that template overrides this file. Ask the author for the template if the document is being prepared for a specific defence; if none is supplied, use this structure and say so.

## Front matter

```
[Universitātes / iestādes nosaukums]
[Fakultāte vai zinātniskais institūts]

[Autora vārds, uzvārds]

[PROMOCIJAS DARBA NOSAUKUMS]

PROMOCIJAS DARBA KOPSAVILKUMS
zinātniskā doktora grāda „zinātnes doktors (Ph.D.)” iegūšanai
zinātnes nozarē [nozare], apakšnozarē [apakšnozare]

Zinātniskais vadītājs:
[grāds, vārds, uzvārds]

[Vieta] [gads]
```

A defence-details block usually follows: date, time, venue, the promotion council, the reviewers (`recenzenti`), and where the thesis can be consulted. These are administrative facts . if they are absent from the English source, do not invent them; list them in the query list as items the author must supply.

Latvian summaries are frequently bilingual, with the full Latvian text followed by the full English text. If that is the required format, keep both versions aligned section by section, with identical numbering, identical figure and table numbers, and identical data.

## Body sections

| Order | Latvian heading | Contents |
|---|---|---|
| 1 | Ievads | opening frame |
| 1.1 | Pētījuma aktualitāte | why the topic matters now, research gap |
| 1.2 | Pētījuma problēma | the problem statement |
| 1.3 | Pētījuma mērķis | one aim, stated as a single sentence |
| 1.4 | Pētījuma uzdevumi | numbered tasks, each starting with an infinitive verb |
| 1.5 | Pētījuma objekts un priekšmets | object = what is studied; subject = the aspect studied |
| 1.6 | Hipotēzes / pētījuma jautājumi | as the source has them |
| 1.7 | Aizstāvēšanai izvirzītās tēzes | the defended propositions, numbered |
| 1.8 | Pētījuma metodes un metodoloģija | design, data, methods, instruments |
| 1.9 | Pētījuma ierobežojumi | limitations |
| 1.10 | Zinātniskā novitāte | what is new |
| 1.11 | Praktiskā nozīme | who can use it and how |
| 1.12 | Darba aprobācija | publications and conference presentations |
| 1.13 | Darba struktūra un apjoms | chapters, pages, figures, tables, references count |
| 2 | [Teorētiskā daļa] | condensed theory chapter |
| 3 | [Metodoloģiskā daļa] | condensed methods chapter |
| 4 | [Rezultāti un to analīze] | condensed results |
| 5 | Secinājumi | conclusions, numbered |
| 6 | Priekšlikumi | recommendations, numbered, each with an addressee |
| 7 | Literatūras saraksts | references, original languages |
| 8 | Pielikumi | appendices, if any |

## Section-level conventions

**Uzdevumi** are written as infinitive constructions: `1. Izpētīt digitalizācijas jēdziena teorētiskās nostādnes.` Not as noun phrases and not as sentences with a subject.

**Aizstāvēšanai izvirzītās tēzes** are assertive declarative statements that the candidate will defend, not questions and not hedged observations. Each is numbered and self-contained. This section is what the council interrogates . translate it with maximum care and back-translate it during QA.

**Secinājumi** and **priekšlikumi** are numbered separately. Latvian practice expects each `priekšlikums` to name its addressee: `Polijas Uzņēmumu attīstības aģentūrai ieteicams...`, `MVU vadītājiem ieteicams...`. If the English source has undirected recommendations, keep them undirected and flag that the Latvian convention expects addressees.

**Darba aprobācija** lists publications in a citation format and conference presentations with conference name, place and date. Publication titles stay in their original language.

**Darba struktūra un apjoms** states counts: `Promocijas darbs sastāv no ievada, trim nodaļām, secinājumiem un priekšlikumiem, literatūras saraksta un [N] pielikumiem. Darba apjoms ir [N] lappuses, tajā iekļauti [N] attēli un [N] tabulas. Literatūras sarakstā iekļauti [N] avoti.` Every number here must be verified against the actual document, not carried over from the English draft, because these counts change when the document is reformatted.

## Heading style

Sentence case, no terminal period, no bold-plus-underline stacking. Numbered with periods after each level: `2.1.`, `2.1.1.`. Keep the numbering identical between the Latvian and English versions when the summary is bilingual.
