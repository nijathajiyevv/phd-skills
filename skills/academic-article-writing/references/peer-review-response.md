# Peer review, revision and rebuttal

A revise-and-resubmit is an acceptance path. Editors read the response letter as evidence of how the authors behave as collaborators. Noble's ten rules (PLOS Comput Biol, 2017) are the common standard: overview then full reviews; polite and respectful; accept the blame; self-contained; respond to every point; typography that aids navigation; begin each response with a direct answer; do what the reviewer asks when possible; be clear about what changed; write it twice if needed (vent first, then the real version).

## Step 1: comment matrix

Parse the decision letter and every review into:

```
| ID | Reviewer comment (verbatim or summarised) | Type (major / minor / clarification / out of scope) | Effort | Decision (accept / partial / decline) | Change and location | Status |
```

Number comments R1.1, R1.2, R2.1. Group duplicates raised by several reviewers. Flag conflicts between reviewers.

## Step 2: response letter

1. Thank the editor and reviewers; summarise major changes (new analyses, restructured sections) first.
2. Quote each comment in full, numbered.
3. Open each reply with a direct answer: done, partially done, or respectfully declined.
4. Quote the revised text inside the response with page and line numbers, so the letter is readable without the manuscript.
5. Use consistent typography to separate comment, reply and new text.
6. When declining, give evidence (data, citations, scope argument), not opinion.

## Rules

- Treat a misreading as a writing failure: fix the manuscript text, not only the reply.
- Do what is feasible and harmless; choose battles.
- Conflicting reviewers: state the conflict and the resolution openly; escalate genuine impasses to the editor.
- Never skip a comment; unanswered points are the most common reviewer complaint.
- Never argue, speculate about reviewer identity or criticise reviewers; the editor chose them.
- Never claim a change without showing where.
- The user decides which requests to decline; the skill states the cost of each choice.

## After rejection

Extract fixable problems from the reviews, revise, reformat for the next venue on the list. Do not resubmit unchanged.
