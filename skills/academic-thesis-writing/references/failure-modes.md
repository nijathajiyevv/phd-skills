# Failure modes

Ordered by severity (a judgement synthesised from the sources, not a measured frequency). Each pairs a detectable symptom with a fix inside the candidate's structure.

| Failure | Detectable symptom | Fix |
| --- | --- | --- |
| No stated contribution | No "this thesis contributes X to Y" in introduction or conclusion | Write before/after statement; test against degree criteria |
| Descriptive literature review | Paragraphs open with author names; no critique; gap appears from nowhere | Reorganise by theme with synthesis matrix; end sections with implications |
| Question-method mismatch | Method cannot produce the type of answer asked (causal question, descriptive design) | Narrow the question or state inferential limits |
| Broken through-line | Research questions not traceable to findings, discussion, conclusion | Traceability table; add or cut |
| Unjustified methodology | Methods described, alternatives never considered | Rationale and rejected alternatives per major choice |
| Recommendations not grounded (applied models) | Proposals unrelated to the analysis findings | Trace each proposal to a finding; justify feasibility |
| Discussion restates results | No citations in discussion | Interpret each finding against the reviewed literature |
| Overclaiming | Generalisation beyond sample; causal verbs for correlation | Calibrate verbs; add scope statement |
| Disconnected papers (by publication) | Papers share no question; no linking text | Paper-to-question matrix; linking sections; integrative discussion |
| Late writing | No full chapter drafts six months before submission | Backward plan; draft methodology and review first |
| Sloppiness | Typos, missing references, inconsistent formatting | Reference manager; full proofread; copy-edit within rules |
| Scope creep | New sub-studies after mid-candidature review | Freeze scope; move to future work |

## Self-deception patterns to challenge (directly but respectfully)

- "I need to read more before I can write." Usually avoidance; writing shows what is missing.
- "My supervisor will tell me if it's wrong." Supervisors miss things; examiners are not the supervisor.
- "The examiners will understand what I meant." They read what is written, selectively.
- "It just needs polishing." Usually the argument is not settled.
