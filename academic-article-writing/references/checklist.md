# Pre-submission checklist

Ordered by rejection cost. Report each item as pass, fail (with location and fix) or not applicable. Phrase every item against the user's actual sections.

## Tailoring
- [ ] Structure and section names match the venue template or the user's outline, unchanged by the skill
- [ ] Function map complete: problem, gap, approach, evidence, interpretation, contribution, limits each located
- [ ] Warned deviations recorded with the user's decision

## Fit and contribution
- [ ] Contribution sentence present in title, abstract, end of introduction, start of discussion
- [ ] Venue scope matched; recent venue papers cited where relevant
- [ ] Before/after statement and nearest-neighbour delta (3 to 5 works) exist

## Argument
- [ ] Introduction names one gap; discussion answers that gap
- [ ] Every claim's verb matches evidence strength
- [ ] Limitations section specific

## Type, rigour and depth
- [ ] Article type named; structure and reporting guideline match the type
- [ ] Reporting checklist completed with section pointers
- [ ] Literature section synthesised (no single-source paragraphs)
- [ ] Methods pass the replication test; deviations and exclusions declared
- [ ] Data, code and materials availability statement
- [ ] Each result in one format chosen by its message; no duplication
- [ ] Each main finding compared with prior work in the discussion

## Integrity
- [ ] Every reference verified to exist and to support its claim
- [ ] Authorship meets ICMJE criteria; contributions statement ready
- [ ] AI use, conflicts, funding, ethics approval disclosed
- [ ] No overlapping publication; similarity check run

## Style and packaging
- [ ] Citations and reference list match the named style; no cited-but-missing or uncited entries
- [ ] Table and figure labels, caption positions and numbering follow the style
- [ ] Every display called out and readable on its own
- [ ] Length, format and figure specifications per author guidelines
- [ ] Anonymised for double-blind review if required
- [ ] Cover letter tailored to this venue
- [ ] Two readers outside the author team have read it cold
