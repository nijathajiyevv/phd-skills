# Novelty, contribution and venue positioning

Lack of novelty and being out of scope are the most common desk-rejection reasons (Menon et al., analysis of 898 rejected manuscripts; median time to desk rejection 3 days versus 42 days after review). Novelty is rarely absent; it is usually unstated or undemonstrated. "No one has done this before" without showing what is now known that was not known before is the classic failure (Gill & Dolan 2015).

## Before drafting

1. **Contribution sentence:** "We show X, which matters because Y, using Z." If it cannot be written, the paper is not ready. Make the working title carry it.
2. **Venue first:** read the venue's aims and scope, 3 to 5 recent papers, and the author guidelines. Write for that readership. Cite the venue's recent work only where genuinely relevant.
3. **Two-minute pitch test:** if the contribution cannot be explained to a colleague outside the subfield in two minutes, it is not distilled yet.
4. **One central contribution.** Multiple loosely linked contributions make each weaker.

## Contribution types to recognise

| Type | Claim shape |
| --- | --- |
| New empirical evidence | First data on X in population or context Y |
| New method or technique | Does Z faster, cheaper, or more validly |
| Method transfer | Established technique applied to a new field or problem |
| New synthesis | Bodies of work never connected, now integrated |
| New interpretation | Known data reread through a different theory |
| Theory test | A theory tested, extended or bounded |
| Replication or negative result | Robustness of a prior finding established or challenged |
| Context transfer | Something known elsewhere shown in a new country, sector or setting |

## The five novelty checks (outline, full draft, pre-submission)

1. **Before/after statement:** one sentence each. Missing or vague: stop and fix before drafting further.
2. **Nearest-neighbour delta:** name the 3 to 5 closest prior works; for each, state the difference in question, population or data, method, and finding. If no row differs meaningfully, the paper is not novel yet.
3. **Significance:** why the delta matters to the target readership. Novel but trivial fails too.
4. **Consistency:** the same contribution appears in title, abstract, last paragraph of the introduction, first paragraph of the discussion.
5. **Evidence of search:** the claim rests on a documented search (databases, terms, date). Under-reading creates false novelty.

Output template:

```
Before: <what was known>
After: <what this paper adds>
Nearest neighbours:
| Work | Question | Data/context | Method | Finding | Delta |
Significance for <venue readership>: ...
Consistency: title / abstract / intro / discussion -> aligned | misaligned at ...
Search basis: <databases, terms, date> | not documented
```

## Edits the skill can propose

- Replace "first study to" with the specific delta and the works it is measured against.
- Narrow an inflated claim to what the data support.
- Reposition an incremental paper as replication, extension or context transfer, and target venues that value it.
- Move the contribution statement to where readers expect it.

## Venue choice

- Match scope before prestige; scope mismatch is the cheapest rejection to avoid.
- Field norms: conferences dominate CS and ML (deadlines, page limits, rebuttal phase, mandatory checklists); journals dominate most other fields.
- Prepare a ranked list of three venues so a rejection triggers reformatting, not re-deliberation.
- Verify legitimacy with Think. Check. Submit. (see `submission.md`).

## Hard limit

The skill cannot certify novelty from its own knowledge. Run or request a literature search and report novelty as "supported by the following comparison", never as fact.
