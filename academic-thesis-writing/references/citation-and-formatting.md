# Citation, caption, numbering and front-matter conventions

The thesis inherits its citation style from the department or supervisor. Delegate bulk reference formatting to a reference manager with the matching CSL style; the skill audits consistency and completeness and never invents missing metadata.

## Citation families

| Family | Examples | In-text | List order |
| --- | --- | --- | --- |
| Author-date | APA 7, Harvard variants, Chicago author-date | (Smith, 2020) | Alphabetical |
| Numeric | IEEE, Vancouver | [1] or superscript by first appearance | Numerical |
| Note | Chicago notes-bibliography, OSCOLA | Footnotes or endnotes | Bibliography |
| Label | Some CS and maths styles | [Smi20] | Alphabetical |

"Harvard" is a generic label, not one standard: get the department's exact variant.

## Style module template

Fill from the department guide; mark unknown fields "check guide".

```
Style / variant:
In-text format (1, 2, 3+ authors):
et al. threshold:
List order and DOI format:
Table label: position, numbering, title format, notes
Figure label: position, numbering, caption format
Headings: numbering depth

```

Known caption rules: APA puts number and title above both tables and figures, notes below, horizontal rules only. IEEE puts "TABLE I" style labels above tables and "Fig. 1." captions below figures. A department guide overrides both.

## Thesis-specific conventions (common practice; regulations and templates override)

| Element | Common convention |
| --- | --- |
| Table and figure numbers | By chapter: Table 3.2, Figure 4.1; separate sequences |
| Appendix items | Letter prefix: Table A.1, Figure B.2 |
| Front matter | Title page, declaration, abstract (sometimes bilingual), acknowledgements, AI-use declaration, contents, lists of tables, figures and abbreviations; often Roman page numbers |
| Headings | Numbered, usually to three levels |
| Equations | Numbered by chapter, (3.1) |
| Cross-references | Generated by the word processor or LaTeX, never typed by hand |
| References | One consolidated list, or per chapter where allowed (common in by-publication theses) |
| Included papers | Keep journal format or reformat, per regulations |

## Checks the skill runs

- Every table and figure numbered in sequence, called out in text, listed in front matter with matching titles
- Caption positions and label formats match the named style everywhere, including appendices and included papers
- In-text citations and the reference list match one to one; one style across all chapters
- Abbreviations defined at first use (per chapter if regulations expect it) and listed
- Reproduced figures carry source and permission
- Unverifiable metadata marked UNVERIFIED
